# brain-wiki

A local-first second brain for AI agents, kept as plain Markdown that you own.

brain-wiki gives every agent you use (Claude Code, Codex, Antigravity, Gemini
CLI, OpenClaw, and any MCP client) one shared, durable memory:

- **Plain files.** A brain is a folder of Markdown notes you can read, edit,
  diff, and sync like any other folder. It opens in Obsidian.
- **Typed connections.** Notes link to each other with a small set of typed
  relations. Contradictions and superseded knowledge are always retrieved
  together with what they qualify.
- **Safe writes.** Agents append raw observations to an inbox. A
  consolidation step folds them into curated notes through small, validated
  operations that can be undone.
- **Any agent.** One plugin bundle, an MCP server, and a CLI.

## Status
