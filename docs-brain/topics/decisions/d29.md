# D29: brain-wiki's own frontmatter fields carry a bw- prefix

brain-wiki's own frontmatter fields carry a `bw-` prefix: relations, claims, stage, and episode provenance. Shared metadata (`id`, `type`, `title`, `aliases`, `tags`, `status`, `created`, `updated`) stays unprefixed. `format` in `brain.toml` names the newest file format a brain may hold; writers raise it one-way, and older tools refuse to open newer brains.

**Alternatives:** No prefix (clashes with other tools' properties); a dotted `brain-wiki.` prefix (Dataview reads dots as nesting); best-effort reads of newer brains (an old reader misses `bw-claims`)
