# D30: Topics form a tree

Topics form a tree: a folder under `topics/` with a hub is a topic at any depth, and its parent is the nearest enclosing topic. A topic is known by a unique slug, not its path, so folders can be reorganized (`brain mv` moves a topic folder). Privacy and agent allowlists inherit down; a sub-topic's hub is implicitly `part_of` its parent's hub, so folders and containment relations form one hierarchy.

**Alternatives:** Flat topics with structure only from relations (cluttered folders, long briefing, guessed map groups); flat topics plus a `group` field (grouping invisible in file browsers); path-based topic ids (break on every reorganization)
