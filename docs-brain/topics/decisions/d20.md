# D20: Hosts' own session stores are a second capture source (harvest, with…

Hosts' own session stores are a second capture source (harvest, with backfill) and can be consulted during consolidation (origin lookup); both opt-in, routed by project, and never required for an episode to make sense. Distillation runs in the host agent via an MCP recipe (brain-wiki still reads, filters, routes, scrubs, and sets provenance), headless from the CLI, or raw; hosts without a reader use a self-read fallback with `taint: unknown`.

**Alternatives:** Hooks as the only capture path; agents reading raw transcripts themselves for all hosts; copying transcripts into the brain
