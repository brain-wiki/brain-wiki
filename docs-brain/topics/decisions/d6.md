# D6: Three write paths: an append-only inbox open to any agent

Three write paths: an append-only inbox open to any agent; curated notes changed through validated ops (consolidation); and direct agent edits that `brain check` validates and records (D28). Human edits are always allowed.

**Alternatives:** Unchecked direct edits by agents; MCP as the only write path
