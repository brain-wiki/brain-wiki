# D26: The tools follow progressive discovery (list, orient, search or browse,…

The tools follow progressive discovery (list, orient, search or browse, read with handles, follow relations with `brain_neighbors`) and borrow the Obsidian CLI's conventions: wikilink-style or exact targets, counts and facets before fetching, `paths` output. The CLI mirrors them: `brain search` (an empty query browses), `brain read --mode outline`, `brain neighbors`, and small listings (`links`, `backlinks`, `tags`, `types`, `orphans`, `unresolved`).

**Alternatives:** One tool per question (every tool description costs context); search only
