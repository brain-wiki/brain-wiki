# D10: Privacy is an ordered level per note/topic plus a maximum per agent…

Privacy is an ordered level per note/topic plus a maximum per agent profile, enforced before ranking. Unrelated spheres (work vs personal) use separate brains.

**Alternatives:** Unordered label sets; embedding-based classification
