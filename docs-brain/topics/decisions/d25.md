# D25: Agents learn about brains from a static block that brain connect writes…

Agents learn about brains from a static block that `brain connect` writes into each host's persistent instructions; the block tells them to call `brain_list` and `brain_orient` when a task may depend on the user's knowledge. No session-start hook delivers the briefing ([[proposal-hooks|proposal]]).

**Alternatives:** A session-start hook as the main path (several hosts have no such event)
