# D28: Agents may edit notes directly when their profile has edit and the…

Agents may edit notes directly when their profile has `edit` and the topic allows it, then run `brain check`, which validates the change (schema, links, claims only superseded, protected files, loss guard) and records it as a run with an undo point.

**Alternatives:** Episodes and consolidation only (they cannot express prose or property updates); unchecked edits
