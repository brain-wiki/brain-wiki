# D23: Plugin MCP entries stay a plain uvx command that works on every…

Plugin MCP entries stay a plain `uvx` command that works on every platform, accepting a slow first start behind a slow package index; `brain connect` is the fast path. Hooks are not in the bundle; `brain connect` writes them with the installed `brain`.

**Alternatives:** Wrapping the MCP entry in `sh -c` with an installed-command and offline fallback (breaks Windows)
