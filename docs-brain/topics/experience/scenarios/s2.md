# S2: Recall during a task

Recall during a task

**What happens:** The agent asks about a past decision. `brain_search` returns the matching notes, plus the newer note for every superseded hit. The agent opens one with `brain_read`, follows its links with `brain_neighbors`, or reads the files directly.
