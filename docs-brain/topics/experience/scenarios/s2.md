# S2: Recall during a task

**Recall during a task.** The agent asks about a past decision.

**Flow (details in):** `search` returns the matching notes plus the newer note for every superseded hit; the agent opens one with `read` and follows its links with `neighbors`, or reads files directly when allowed. [[index-and-retrieval|04]]
