# S11: An agent builds its own knowledge

**An agent builds its own knowledge.** A long-running assistant learns how the user's tools, services, and projects behave.

**Flow (details in):** It writes what it learns into notes directly, citing episodes and pages in `bw-sources` and validating each edit, or logs episodes to consolidate later; later sessions on any host recall the notes with their sources.
