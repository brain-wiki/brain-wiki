# S11: An agent builds its own knowledge

An agent builds its own knowledge

**What happens:** A long-running assistant learns how the user's tools, services, and projects behave. It writes what it learns into notes, cites episodes and pages in `bw-sources`, and validates each edit, or logs episodes to consolidate later. Later sessions on any host recall the notes with their sources.
