# S4: Consolidation

**Consolidation.** Pending episodes are folded into topic notes.

**Flow (details in):** The user asks their agent to consolidate: `brain consolidate --prepare` hands it the pending episodes with candidate notes, it edits and validates the notes in the session, where the user can watch and steer, and `--done` archives the episodes.
