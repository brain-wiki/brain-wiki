# S0: Onboarding

Onboarding

**What happens:** The user installs the plugin and says "set up brain-wiki". The setup skill walks through installing, creating a brain or importing a vault, connecting other agents, choosing which brains each may use, and turning on harvest, with a dry run before every write.
