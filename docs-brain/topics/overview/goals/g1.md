# G1: Files are the source of truth

Files are the source of truth. Everything the system knows is in the brain directory, people can read and edit it with any editor, and it works in Obsidian.

**How we check it:** Deleting and rebuilding the index loses nothing. A brain edited in Obsidian passes lint.
