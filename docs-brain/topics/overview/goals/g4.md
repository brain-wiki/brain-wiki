# G4: Writes are safe

**Writes are safe.** Untrusted content cannot become a standing directive automatically; every change to a note is reversible.

**How we will know (v0.1):** Rules change only with the user's verbatim words and confirmation; `brain undo` restores the exact prior bytes of a run; git restores a direct edit that `brain commit` recorded.
