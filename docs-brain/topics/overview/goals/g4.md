# G4: Writes are safe

Writes are safe. Untrusted content cannot become a standing directive, and every change to a note can be undone.

**How we check it:** Rules change only from the user's own words, with confirmation. `brain undo` restores the exact bytes from before a run, and git restores a direct edit that `brain commit` recorded.
