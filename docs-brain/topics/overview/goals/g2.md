# G2: Works with the agents people use

**Works with the agents people use.** One brain serves Claude Code, Codex, Antigravity, OpenClaw (bundle mode), Cursor, and generic MCP clients.

**How we will know (v0.1):** The plugin loads in each host; `brain connect <host>` wires it; an end-to-end smoke test per host passes (see [[agent-integrations|08]]).
