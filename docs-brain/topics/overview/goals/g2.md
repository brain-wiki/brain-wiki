# G2: One brain works with the agents people use

One brain works with the agents people use: Claude Code, Codex, Antigravity, OpenClaw (as a bundle), Cursor, and other MCP clients.

**How we check it:** The plugin loads in each host, `brain connect <host>` wires it, and a smoke test per host passes ([[agent-integrations|agent integrations]]).
