# M12: Agent context and discovery (D25–D28)

Agent context and discovery (D25–D28)

**Delivers:** Static instruction block written by `brain connect` per host; `brain_list`; briefing with "what's in this brain"; search filters, browse, counts, facets, paths output; handles in reads; `brain_neighbors`; Obsidian-style CLI commands; checked agent edits (`brain check`, pending edits, `brain restore`, `edit` capability, topic `agent_edits`)

**Exit criteria:** Unit and MCP tests per tool; connect writes and uninstalls the block for every host in fixtures; edits that delete a claim, lower privacy, or touch protected files are refused; the retrieval failures found on the OpenClaw sample ("latest release", "what changed last week", sentence queries) pass as typed calls
