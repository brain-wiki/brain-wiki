# Q2: Should sources with external inputs route consolidation runs to review…

**Should sources with external inputs route consolidation runs to review by default?** (`review_external`)

**Options:** false: their claims land marked `[unverified]`; true: every run touching web-derived episodes waits for review

**Recommendation:** false. Coding sessions use web search constantly; true would put nearly every run in review. Rules stay protected regardless.
