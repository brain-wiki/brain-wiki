# Q2: Should tainted sources route consolidation runs to review by default?…

**Should tainted sources route consolidation runs to review by default?** (`review_tainted`)

**Options:** false: tainted claims land marked `[unverified]`; true: every run touching web-derived episodes waits for review

**Recommendation:** false. Coding sessions use web search constantly; true would put nearly every run in review. Rules stay protected regardless.
