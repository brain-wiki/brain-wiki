# T-13: Antigravity /schedule

Antigravity `/schedule`: does it accept a full multi-line prompt, in which workspace does the scheduled run start, and does it survive restarts in the CLI as well as the desktop app?

**Test:** **CLI (agy 1.3.3):** `/schedule "* * * * *" <prompt>` creates an in-session cron job; it ran each minute in the session's workspace and stopped when the session exited. `brain schedule show` now says so. Multi-line prompts (the printed line is one line) and the desktop app not tested.
