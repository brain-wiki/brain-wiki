# Q3: Default privacy levels

**Default privacy levels**

**Options:** `default/sensitive/secret`; or a single level until the user opts in

**Recommendation:** Ship the three names in the template, all content `default`, agent profiles defaulting to `default`. Users who never think about it see no difference.
