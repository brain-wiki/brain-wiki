# Q1: How should session capture work when enabled?

**How should session capture work when enabled?**

**Options:** (a) *Raw*: the stop hook copies a bounded transcript tail into an episode, no model involved. (b) *Prompted*: the stop hook asks the agent, once per session, to call `brain_log_episode` with its own summary (hosts that support "continue with reason" from a stop hook). (c) Both, per host.

**Recommendation:** (c), with (b) as default where supported: the agent's own summary is far more useful than a raw tail, costs one short turn, and needs no transcript parsing. Raw remains for hosts without that ability.
