# T-1: Does Antigravity accept a root plugin.json with Agent Plugins fields…

Does Antigravity accept a root `plugin.json` with Agent Plugins fields (`$schema`, `version`, `extensions`)? Its published schema is closed.

**Result or test:** **Verified** (agy 1.3.3, 2026-10-11). `agy plugin install` accepts the full manifest. In a session the agent lists the plugin's three skills, calls its MCP tools, and gets its `always_on` rules.
