# T-1: Does Antigravity accept a root plugin.json that carries Agent Plugins…

Does Antigravity accept a root `plugin.json` that carries Agent Plugins fields (`$schema`, `version`, `extensions`)? Its published schema is closed.

**Test:** **Verified (agy 1.3.3, 2026-10-11):** `agy plugin install` accepts the full Agent Plugins manifest, and in a session the agent lists the plugin's three skills, calls its MCP tools, gets its `always_on` rules, and runs its hooks.
