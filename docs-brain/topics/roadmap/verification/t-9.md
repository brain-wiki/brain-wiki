# T-9: Hook timeouts and output size limits per host in practice

Hook timeouts and output size limits per host in practice

**Test:** **Antigravity:** a hook past its timeout is killed, logged, and its output dropped; the model call then proceeds. Hooks run one after another before every model call, so a slow hook delays each call. An `ephemeralMessage` is cut at about 49 KB with a notice appended. Other hosts not tested.
