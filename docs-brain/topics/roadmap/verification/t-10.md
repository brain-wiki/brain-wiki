# T-10: Does uvx --from brain-wiki==<version> brain …, as marketplace installs…

Does `uvx --from brain-wiki==<version> brain …`, as marketplace installs run it, start fast once cached?

**Result or test:** **No** (Linux, 2026-10-11). Online `uvx` checks the package index on every call, which took 23 s behind a slow index even when cached. `uvx --offline` takes 0.13–0.21 s and an installed `brain` 0.08–0.11 s. This killed hooks, which were later removed, and slows the MCP server's start (D23). macOS not timed.
