# T-10: Does uvx --from brain-wiki==<version> brain hook … (used by marketplace…

Does `uvx --from brain-wiki==<version> brain hook …` (used by marketplace installs) fit the 300 ms hook budget once cached?

**Test:** **No (Linux, 2026-10-11):** online `uvx` revalidates the index on every call, 23 s behind a slow package index even when cached, so Antigravity killed the hook before every model call. `uvx --offline` takes 0.13–0.21 s and an installed `brain-wiki` 0.08–0.11 s. Hooks were later removed altogether ([[proposal-hooks|proposal]]); the MCP server's start has the same cost (agent integrations §3). macOS not timed.
