# T-2: Does Antigravity expand a plugin-root variable in plugin…

Does Antigravity expand a plugin-root variable in plugin `mcp_config.json` and `hooks.json`, and what working directory do plugin hooks get?

**Test:** **Verified (agy 1.3.3):** no plugin-root variable is set (`PLUGIN_ROOT`, `PLUGIN_DIR`, `PLUGIN_DATA`, `extensionPath` all unset). Hook commands run through a shell (`$HOME` and `${VAR:-x}` expand) with the plugin folder as working directory, the host's environment, `ANTIGRAVITY_CONVERSATION_ID`, and stdin closed after the payload. The project came from the payload's `workspacePaths`.
