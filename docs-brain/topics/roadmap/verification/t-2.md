# T-2: Does Antigravity expand a plugin-root variable in the plugin's…

Does Antigravity expand a plugin-root variable in the plugin's `mcp_config.json` and `hooks.json`, and what working directory do plugin hooks get?

**Result or test:** **Verified** (agy 1.3.3). No plugin-root variable is set. Hook commands run through a shell with the plugin folder as working directory, the host's environment, `ANTIGRAVITY_CONVERSATION_ID`, and stdin closed after the payload. The project comes from the payload's `workspacePaths`. brain-wiki ships no hooks now.
