# T-3: What is the line schema of Antigravity's transcript JSONL?

What is the line schema of Antigravity's transcript JSONL?

**Result or test:** **Verified** for structure (2026-10-11). Steps carry `step_index`, `source`, `type`, `status`, `created_at`, and `content`. Types include `USER_INPUT`, `PLANNER_RESPONSE` (with `tool_calls`), `EPHEMERAL_MESSAGE`, and tool steps; MCP calls are `call_mcp_tool` with `ServerName`, `ToolName`, and `Arguments`. `transcript.jsonl` cuts long steps to about 4 KB, so the reader prefers `transcript_full.jsonl`. Since 1.3 the CLI writes `conversation_summaries.db` with `workspace_uris`, so its conversations route by working directory.
