# T-3: Antigravity transcript JSONL line schema

Antigravity transcript JSONL line schema

**Test:** **Verified for structure (2026-10-11):** steps carry `step_index`, `source`, `type` (`USER_INPUT`, `PLANNER_RESPONSE` with `tool_calls[{name, args}]`, `EPHEMERAL_MESSAGE`, tool step types), `status`, `created_at`, `content`. MCP calls are `call_mcp_tool` with `ServerName`, `ToolName`, `Arguments`. `transcript.jsonl` cuts long steps to about 4 KB; `transcript_full.jsonl` keeps them and is what the reader prefers. The CLI writes `conversation_summaries.db` (with `workspace_uris`) since 1.3, so its conversations route by working directory.
