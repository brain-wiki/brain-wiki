# T-5: Can an Antigravity headless run be restricted to no tools (custom agent…

Can an Antigravity headless run be restricted to no tools (custom agent `tools: []`)?

**Test:** **No (agy 1.3.3):** with `tools: []` or `tools: [finish]`, `init.tools` still listed all 59 tools. A tool call that headless mode denies ends the turn with no output, so the presets' prompt now starts with a no-tools preamble; the consolidation run then answered with ops directly.
