# T-5: Can an Antigravity headless run be limited to no tools (a custom agent…

Can an Antigravity headless run be limited to no tools (a custom agent with `tools: []`)?

**Result or test:** **No** (agy 1.3.3). With `tools: []` or `tools: [finish]`, all 59 tools stayed listed. A tool call that headless mode denies ends the turn with no output, so every preset prompt starts with a preamble telling the model not to call tools.
