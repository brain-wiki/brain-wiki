# Q8: Harvest default

**Harvest default: distill or raw?**

**Options:** Distill with the configured preset (cleaner episodes, model cost); raw (no model, verbose episodes for consolidation to distill)

**Recommendation:** Distill when a command-backend preset is configured, raw otherwise; a backfill dry run shows the token estimate before anything is spent.
