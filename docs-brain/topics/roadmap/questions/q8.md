# Q8: Should harvest distill sessions with a model by default, or write them…

Should harvest distill sessions with a model by default, or write them raw?

**Options:** Distill with a preset (cleaner episodes, model cost); raw (no model, longer episodes)

**Status and recommendation:** Decided in code: `brain harvest --apply` distills with the `harvest.distill` preset, `claude-code` when unset, and `--raw` writes turns without a model. Running `brain harvest` without `--apply` lists the sessions with token estimates before anything is spent.
