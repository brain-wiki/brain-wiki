# Q12: What may agents learn without the user? Rules always need the user's…

What may agents learn without the user? Rules always need the user's words, but agents also learn procedures, such as "tests in this repo need the emulator".

**Options:** (a) Procedures are ordinary notes, found by search. (b) A `howto` note type that orientation shows for the matching project, below the rules and never as a directive. (c) Agents propose rules for the user to approve, and nothing else.

**Status and recommendation:** Open. Recommendation: (b), so agents get their own lessons back at session start without the authority of rules. Today `howto` is an ordinary type and orientation does not list such notes.
