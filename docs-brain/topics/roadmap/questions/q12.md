# Q12: What may agents learn without the user? Rules always need the user's…

**What may agents learn without the user?** Rules always need the user's words. Agents also learn procedures ("tests in this repo need the emulator").

**Options:** (a) Procedures are ordinary notes, recalled by search only. (b) A `howto` note type that orientation surfaces for the matching project, below rules, never as a directive. (c) Let agents propose rules for one-click approval (already possible) and nothing else.

**Recommendation:** (b): agents get their own lessons back at session start without granting them the authority of rules.
