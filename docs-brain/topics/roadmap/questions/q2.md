# Q2: Should consolidation runs that touch episodes with external inputs wait…

Should consolidation runs that touch episodes with external inputs wait for review by default (`review_external`)?

**Options:** No, and mark their claims `[unverified]`; yes, every such run waits for review

**Status and recommendation:** Decided: withdrawn in format 3. Consolidation has no review step and `[unverified]` is gone (D34). Rules still need the user's own words.
