# Q9: Where does agent-learned knowledge live? (see 01 §2.1)

**Where does agent-learned knowledge live?** (see [[01-21-two-uses|01 §2.1]])

**Options:** (a) Mixed in the user's topics, told apart only by per-claim `origin`. (b) Agent-owned topics: a topic flag (`owner = "agents"`) that consolidation may grow freely while user topics only gain inbox proposals. (c) A separate brain per agent or fleet, with a manifest `kind = "agent"` for brains no human curates.

**Recommendation:** (b), with (c) available through the same flag at brain level: one brain stays the default, user notes are protected from agent sprawl, and a standalone agent can still own a whole brain. **Open.** Format 3 removed per-claim `origin`, so (a) now means no distinction at all.
