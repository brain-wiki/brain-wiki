# Q9: Where does knowledge that agents learn live? See overview §2.1

Where does knowledge that agents learn live? See [[overview-21-two-uses|overview §2.1]].

**Options:** (a) Mixed into the user's topics, with nothing telling them apart. (b) Topics owned by agents, marked with a topic flag such as `owner = "agents"`: agents grow them freely, while user topics gain only inbox episodes. (c) A separate brain per agent or fleet, marked in its manifest with `kind = "agent"`.

**Status and recommendation:** Open. Recommendation: (b), with (c) available through the same flag on a whole brain. One brain stays the default, user notes are protected from agent sprawl, and a standalone agent can still own a brain.
