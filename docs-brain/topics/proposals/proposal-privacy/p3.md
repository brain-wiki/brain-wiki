# P3: brain-wiki enforces a level where it controls the flow, and tells the…

brain-wiki enforces a level where it controls the flow, and tells the host where it does not.

**Why:** It controls its tools, hooks, packets, writes, and exports; it does not control the host's model or tool calls.
