# T15: A fake "brain-wiki" plugin in a marketplace

A fake "brain-wiki" plugin in a marketplace.

**Mitigations:** The docs name the official sources (repository, PyPI, registry name), and the plugin manifests point to the official package.

**Residual risk:** Users must install from the official source.
