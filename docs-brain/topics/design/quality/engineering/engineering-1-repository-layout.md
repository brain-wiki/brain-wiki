# Repository layout

The repository root is also the plugin root for every supported host
([[d14-repo-is-plugin-root|D14]]), so some root names are
reserved by hosts and hold only plugin content.

```text
brain-wiki/
├── plugin.json                  plugin manifest (Agent Plugins format, with extensions["com.openai"]); also read by Antigravity
├── mcp.json                     MCP server for Agent Plugins hosts (Codex, ChatGPT desktop, OpenClaw)
├── .mcp.json                    MCP server for Claude Code
├── mcp_config.json              MCP server for Antigravity
├── server.json                  MCP Registry entry
├── .claude-plugin/
│   ├── plugin.json              Claude Code plugin manifest
│   └── marketplace.json         marketplace listing this repo as one plugin
├── rules/brain-wiki.md          Antigravity rule (trigger: always_on), generated from the static instruction block
├── skills/                      brain, brain-setup, brain-maintain, shared by all hosts
│
├── src/brainwiki/               the Python package (§2)
├── tests/                       pytest suites; synthetic fixtures in tests/fixtures/
├── docs/                        user/, design/, decision/, roadmap/, proposal/
├── docs-brain/                  docs/ as a brain, generated by scripts/build_docs_brain.py
├── scripts/                     check, visibility, version sync, docs brain, visualizer bundle check
├── .github/workflows/           ci.yml and release.yml
├── pyproject.toml
├── README.md, LICENSE, CONTRIBUTING.md, SECURITY.md, CHANGELOG.md
├── AGENTS.md                    guide for coding agents working on this repository
└── .pre-commit-hooks.yaml       exposes `brain lint --staged` to the pre-commit framework
```

These root names are interpreted by at least one host when the repository
is installed as a plugin, and nothing else may use them: `plugin.json`,
`mcp.json`, `.mcp.json`, `mcp_config.json`, `settings.json`, `.lsp.json`,
`skills/`, `agents/`, `commands/`, `hooks/`, `rules/`, `output-styles/`,
`sidecars/`, `.claude-plugin/`, `.codex-plugin/`, `.cursor-plugin/`.

Developer instructions must not reach users' sessions. Whether any host
loads a plugin-root `AGENTS.md` (or `GEMINI.md`, which Antigravity treats
like `AGENTS.md` in workspaces) into a user's session is unverified. The
repository has no `GEMINI.md`, and its `AGENTS.md` is short and opens with
a line telling any agent that is not developing brain-wiki to ignore it.
Test item T-4 in [[verification|verification]] checks this.
