# D3: Frontmatter is flat (scalars and lists of scalars) and holds metadata…

Frontmatter is flat (scalars and lists of scalars) and holds metadata only (D32). Format 2 kept claims and relations there as lists of strings (`bw-claims`, `bw-<verb>`); format 1 kept them in `## Claims` and `## Relations` body sections.

**Alternatives:** Nested YAML objects (Obsidian cannot show or edit them); knowledge in properties (format 2: empty bodies, dead links inside facts, every fact edit a YAML edit)
