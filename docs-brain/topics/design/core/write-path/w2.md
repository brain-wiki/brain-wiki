# W2: A note is an ordinary Markdown file that agents and people edit…

A note is an ordinary Markdown file that agents and people edit directly. brain-wiki checks its frontmatter, not its meaning.

**Why:** Facts live in the body ([[brain-format-6-notes|brain format §6]]). See [[d34-direct-edits|D34]].
