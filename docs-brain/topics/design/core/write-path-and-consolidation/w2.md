# W2: A note is an ordinary Markdown file that agents and people edit…

A note is an ordinary Markdown file that agents and people edit directly; brain-wiki checks its frontmatter, never its meaning.

**Why:** Facts live in the body ([[02-6-notes|02 §6]]); a protocol for every edit was heavier than the common case needs.
