# How this brain is organized

- Each top-level folder is one area: Preferences, Projects, Systems,
  Playbooks, People.
- File a note in the area it is mainly about, and link it from the others
  instead of copying it. A decision lives in the project that made it; the
  system it changed links to it.
- Add a top-level folder only for an area none of these covers, and tell the
  user you did.
- Name a note's file after its title, in Title Case
  (`Use SQLite FTS5 for Local Search.md`).
