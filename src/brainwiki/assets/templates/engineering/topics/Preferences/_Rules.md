# Preferences

- One note per subject (`Code Style.md`, `Code Review.md`, `Tools.md`), one
  preference per bullet.
- Record only what the user said, or showed more than once, and cite where it
  came from in `bw-sources`.
- When a preference changes, change its bullet; do not keep both.
- A directive the user wants applied in every session belongs in `rules.md`,
  which only the user changes. Suggest it to them instead of writing it here.
